# 课后邦企业官网与 CMS

蓝白企业官网，包含公司介绍、产品与服务、分类团队、公司动态、文章详情和联系方式。后台支持各栏目增删改、文章草稿和发布，内容保存到本地文件，重启后保留。

## 启动

需要 Node.js 20 或以上，无需安装第三方依赖。

```powershell
npm start
```

官网：http://127.0.0.1:3000 ，后台：http://127.0.0.1:3000/admin 。默认仅监听本机。

首次启动自动生成随机管理密钥，读取方式：

```powershell
Get-Content .\data\admin-token
```

将密钥输入后台登录页。密钥只保留在当前浏览器标签页会话中，退出即清除。也可通过 `ADMIN_TOKEN` 环境变量设置密钥。请勿把密钥文件提交到版本管理。

## 内容维护

- 网站设置：品牌、首页文案、公司介绍、电话、邮箱、地址、备案信息。
- 产品与服务：分类、名称、简介、服务要点。
- 课程目录：按用户提供的《课后邦-课程手册(1).pdf》整理了 55 门课程，分为美育、益智、科技、劳动四类。官网每类先展示 6 门，支持展开全部；课程详情在站内弹窗中显示，无需打开或下载 PDF。后台可编辑课程名称、分类、卡片摘要、详细介绍及学习内容。课程摘要为官网改写，不作教学效果承诺；详细介绍根据用户粘贴的课程内容整理。
- 专业团队：姓名、职称、分类、简介。点击成员照片选择本机图片上传，支持 JPG、PNG、WebP，单张不超过 5 MB；预览确认后点击“保存并更新官网”。上传失败保留原照片。图片保存在 `data/uploads/`（设置 `DATA_DIR` 时随数据目录存储），备份时需一并保留。
- 公司动态：标题、分类、日期、摘要、纯文本正文、公众号原文链接及公开发布开关。
- 修改后点击“保存并更新官网”。未发布文章不会出现在公开 API 中。
- 团队分类自动从成员资料生成；列表顺序等于展示顺序。当前版本适合单管理员维护。

## 资料来源与待确认内容

文字及人物照片来自用户提供的《课后邦团队介绍9.21.pptx》。`reference/slides.json` 保留提取的原始文字。首页首屏使用用户提供的室内环境照片。首页宣传语与服务分组是根据资料拟定的官网文案，应由企业确认后上线。

两篇公众号文章未能读取原文，仅将用户提供的链接保存为未发布草稿，未编造文章标题、日期、内容或项目案例。引用的 ChatGPT 对话在当前工具环境下不可读取。取得原文后可直接补入后台。

PPT 第 2、8、9 页对部分技术岗位有不同表述。首版将戴鹏标注为“技术研发团队”，待确认统一的职称。未使用个人服务经历作为公司整体业绩。

上线前补齐公司法定名称、对外联系方式、地址、备案资料、公众号内容，以及授权使用的案例资料；确认照片及公开职称。当前联系区没有提交表单，不会假装收集或发送咨询。

## 部署边界

当前交付是可运行的本地 CMS 首版，尚未部署到公网。生产环境需配置域名、HTTPS 反向代理、持久化磁盘、备份和登录请求限流。多管理员权限、操作审计和公众号自动同步尚未实现。

可设置 `HOST`、`PORT`、`DATA_DIR` 与 `ADMIN_TOKEN` 环境变量。`data/content.json` 为运行内容；`data/seed.json` 仅用于首次初始化。备份运行数据后再迁移。静态服务只公开 `public/`，管理 API 使用随机密钥鉴权，写入采用临时文件加替换方式。

## 验证

官网支持课程详情弹窗、返回顶部以及微信、视频号、快手、抖音二维码放大查看。二维码使用用户提供的原图。

## GitHub 备份

按项目约定，在每次修改前和验证完成后提交、推送到 `weekomen/khfwcms`。执行 `node scripts/backup-content.mjs` 更新公开内容快照，再提交源码和素材。仓库为公开仓库，不包含管理密钥、未发布文章、临时文件及完整运行数据库。

恢复公开内容时，把 `backups/published-content.json` 复制到 `data/content.json`，把 `backups/uploads/` 中的图片复制到 `data/uploads/`；管理密钥由新环境重新生成。恢复前应保存原有运行数据。未发布文章需另行做私有备份。

## 自动检查

```powershell
npm test
```

验证内容校验、管理鉴权、草稿隔离、发布、重启持久化及私有文件不可访问。
