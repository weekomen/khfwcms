## 上线检查

执行人对每项记录“通过 / 不通过 / 不适用”、时间及证据。内容写入、上传、改密和恢复演练先在隔离验收环境操作；正式环境需要变更时由对应发布或运维负责人安排，完成后恢复确认的公开内容。

### 代码、数据和进程

- [ ] 校验 ZIP 的 `.sha256` 以及包内清单，确认提交号与本次记录一致；运行 `npm test` 并保存结果。
- [ ] 确认生产使用一个 Node 进程和一个持久化 `DATA_DIR`；运行内容可写，源码与凭据权限符合部署文档。
- [ ] 明确使用公开快照初始化还是完整私有迁移。完整迁移停服后进行，并核对草稿、上传图片和凭据；未用 seed 覆盖已有运行数据。
- [ ] 系统服务能够启动、重启并按计划自启动；重启后内容和图片仍在，旧登录会话已失效。
- [ ] Node 仅监听回环地址，公网不能直连 Node 端口；日志不包含密码或完整认证请求。

### 域名、TLS 和入口

- [ ] `kehoubang.cn` 与 `www.kehoubang.cn` 的实际 DNS 指向预期官网入口，HTTPS 证书覆盖两者且有效。
- [ ] `http://kehoubang.cn/`、`http://www.kehoubang.cn/` 均转到裸域 HTTPS；`https://www.kehoubang.cn/` 返回 `308` 至裸域 HTTPS，无重定向循环。
- [ ] 验证路径和查询参数保持，例如 `https://www.kehoubang.cn/admin?from=www` 跳到 `https://kehoubang.cn/admin?from=www`。
- [ ] 官网环境为 `PUBLIC_ORIGIN=https://kehoubang.cn`、`TRUST_PROXY=loopback`，反代保留裸域 Host 并覆盖正确协议头；从规范 `/admin` 地址登录。
- [ ] 证书续期检查已执行，域名和证书到期通知责任人明确。
- [ ] `khb.kehoubang.cn` 没有被当作本仓库 CMS 的别名。其上线由业务系统负责人单独提供源码/上游服务并验收；仅完成 DNS 解析不视为业务系统已部署。
- [ ] 域名切换前保存旧 DNS 值与 TTL，核对原站仍需保留的路径；三份在线资料的完整文件已迁入新入口或有经验证的原托管路由。保留旧入口和回退方案直到验收通过。

### 官网与 CMS

- [ ] 电脑和手机首页素材正常，4 张服务卡片的说明与要点匹配 CMS，页面无横向溢出。
- [ ] 每类课程在 ≤600px 默认 3 门、其余宽度 6 门；展开/收起和课程详情弹窗正常，团队切换不会改变课程分类状态。
- [ ] 页眉的“课程手册 / 一校一案 / 公司展册”及产品栏目两处资料链接在新标签页打开正确 URL；横屏手机可滚动点到菜单末项。三个阅读器实际可翻页，图片、脚本及 PDF 无 404；不能仅用首页链接存在或阅读器入口返回 200 代替验收。
- [ ] 已部署返回按钮 JS/CSS 并合并 Nginx HTML 过滤（或由维护人修改阅读器 HTML）；三个阅读器及手机子页面都有唯一的“返回官网”按钮，可在当前标签页回到官网，不影响原页面翻页、缩放和导航。实际全屏模式也已核验。
- [ ] 团队默认一排，可按分类展开；公开新闻使用 HTTPS 原文在新标签页打开，未发布文章不出现在公开 API。
- [ ] 日间、夜间、跟随系统以及刷新后的主题偏好正常；二维码放大、电话/邮箱链接和返回顶部可用。
- [ ] 企业确认真实联系信息、名称、公开职称、文章日期及所有素材授权；数据数量与本次确认内容一致。
- [ ] 初始化凭据交给实际管理员；先强制改密，再用新密码登录。使用 HTTPS，Cookie 为 HttpOnly / SameSite=Strict / Secure，未登录不能读取管理内容。
- [ ] 在验收数据上完成编辑、保存、发布/撤下、上传图片并重新读取；超过 5 MB 或不支持格式的上传被拒绝。
- [ ] 退出、改密、会话过期后旧会话不能继续管理；未保存编辑可在保持当前页面时重新登录恢复。
- [ ] 检查跨来源/缺失 CSRF 的写请求被拒绝、登录限流生效。高频测试只在隔离环境执行，避免锁定正式后台。

### 备份与恢复

- [ ] 公开 GitHub 备份只含允许公开的源码、素材及快照；没有运行草稿、认证文件、环境文件、日志或原始工作文件。
