1．使用范围与核对日期

供公司官网与课后邦平台维护人员查阅。依据 2026 年 9 月 30 日上线验收及随后读取的生产 Nginx、目录信息整理。本手册是核对快照，不会自动反映后续服务器变更。

域名、URL 路径、磁盘目录是不同层次。Nginx 根据域名及路径分配请求；URL 中的目录名不一定对应同名磁盘文件夹。本文列出已核对的主要服务路径、已配置的特殊路径及相关磁盘目录，不逐项列出 Java 的全部业务 API、历史上传文件或所有 DNS 记录。

3．URL 路径与处理关系

以下以主域为基准。路径中的“…”表示子路径，不是需要输入的字符。

URL 路径作用 / 行为对应服务或目录
/、/index.html官网首页官网 Node → /opt/khfwcms/current/public/index.html
/admin、/admin.html官网管理页面官网 Node → public/admin.html；管理 API 单独认证
/api/content读取公开内容，只展示已发布新闻Node → /var/lib/khfwcms/content.json
/api/admin/login、session、logout、password后台认证、会话、退出、改密官网 Node；登录与改密限速
/api/admin/content读取、保存后台内容官网 Node；认证及 CSRF 保护
/api/admin/images后台图片上传官网 Node → /var/lib/khfwcms/uploads/
/assets/官网和旧业务资源兼容先查原 web/assets/；不存在时转官网 Node。官网固定资源来自 public/assets/，后台上传资源来自持久化 uploads/
/admin.css、admin.js、app.js、courses.css、courses.js、platform-entry.js、site-theme.css、style.css、theme.css、theme.js、upload.css官网根目录的脚本与样式精确匹配后转官网 Node
/cloud、/cloud/…补齐斜线 / 原业务接口Nginx → Java；包括原登录、业务及回调所经接口
/cloud/profile/upload/…上传文件访问及缓存配置Java 127.0.0.1:8080；catalog-display/v1/ 有更具体的缓存路由
/profile、/profile/…补齐斜线 / 文件访问/profile/ → Java 8080 的 /cloud/profile/；文件根为 /data/uploads/
/profile/private-course-resources/…禁止匿名直链私有课件返回 404；不能用公共文件方式管理私有课件
/app、/app/…、/app/assets/…家长 / 教师 H5 及其资源原业务 web/app/；页面回退 app/index.html，资源不存在返回 404
/parent/…、/teacher/…兼容旧 H5 地址分别跳转 /app/parent/… 与 /app/teacher/…
/deployment-board/…业务发布记录看板127.0.0.1:18770；主域收到新业务域 Referer 时跳回 khb 同路径
/_AMapService/…地图代理高德服务；v4/map/styles 有专门规则；密钥不写入本手册
/miniapp-uat/cloud、/miniapp-uat/cloud/…历史配置的验收接口入口补斜线后代理 127.0.0.1:18083/cloud/；本次仅确认配置存在，未确认验收服务当前可用
/cloud/swagger-ui*、swagger-resources/、webjars/、v2/api-docs、v3/api-docs*、druid/诊断 / API 文档入口限制返回 404
/#/...旧业务平台书签官网脚本跳转 khb 子域，保留参数和 hash；# 后的内容不是磁盘目录
/#home 等官网章节锚点仍留在官网页面；不是服务器路由

其他旧图片、脚本、字体等扩展名路径由原静态文件规则处理；其余主域路径转官网服务，不存在的文件不自动成为页面。隐藏文件路径有拒绝规则。

khb 子域：首页及普通前端路径使用原 web/，前端路由回退到业务 index.html；共用旧 /cloud/、/profile/、/app/、地图、看板等配置。khb 的 /admin 不是官网内容后台。HTTP 的 /.well-known/acme-challenge/ 使用 /var/www/letsencrypt，用于证书验证。

7．需要修改时去哪里

要做的事情正确位置核对事项

上传官网图片官网后台上传功能实际图片写入持久化 uploads/；URL 使用 /assets/upload-…
改官网布局、菜单或固定样式独立官网源码仓库的 public/测试、创建发布版本、备份后更新；不要只改线上临时文件

把第 3 份放到官网菜单官网导航 / 正文入口代码先确认资料名称及栏目；文件已存在不代表菜单已添加
改业务功能或 H5课后邦业务源码与发布流程不是官网 CMS 管理范围
改域名分流或代理对应 Nginx 配置先备份，nginx -t 通过后平滑重载
官网入口回退本次备份目录中的 rollback-existing-host.py仅按上线交接操作；校验配置哈希，保留官网数据和 khb 域名

8．只读核对命令

下面命令在已登录的服务器终端执行，不修改文件或重启服务。无需把任何密码、认证文件内容或完整含密钥配置复制到聊天中。

# 查看 current 实际指向
readlink -f /opt/khfwcms/current
readlink -f /data/apps/edu-feiyue/current

# 查看服务状态
systemctl is-active nginx khfwcms edu-server edu-server-v4

# 校验 Nginx 语法（不重载）
nginx -t

# 核对三个 HTTPS 入口
curl -I https://kehoubang.cn/
curl -I https://www.kehoubang.cn/
curl -I https://khb.kehoubang.cn/

# 查看资料目录与文件名（不读取文件内容）
find /data/uploads/upload/pdf -maxdepth 2 -type d
find /data/uploads/upload/pdf/3 -maxdepth 2 -type f

# 取官网公开内容中的数量
curl -fsS https://kehoubang.cn/api/content | python3 -c 'import json,sys; d=json.load(sys.stdin); print("新闻:",len(d["news"]),"课程:",len(d["courses"]))'

上线时公开内容为两篇新闻、55 门课程；后台编辑后数量可以正常变化。HTTP 200 只证明请求成功，业务验收仍需登录并查看实际页面、图片和文件。
